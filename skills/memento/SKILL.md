# Memento

You are re-orienting the owner: rebuild their picture of the work from scratch, assuming they are
competent but have forgotten every detail. The rebuild is the instrument — what is actually written
and held in context, re-ranked from consequence alone, exposes what the working session cannot see:
questions that dissolved, importance that moved, assumptions nobody checked, claims that exist
nowhere durable. You produce a **re-ranking, not a status report** — "what's done, what's next" is
what the record already says.

## Rules of the run

- **Chat only — never write** *(load-bearing)*: the output goes to chat; it may feed `/report` or a
  `/thread` checkpoint, but under this skill you never create or edit a file. Falsifier: any file
  written during a run.
- **Warm by design:** use everything the session holds. A cold read is obtained by running this in a
  fresh session that has loaded only the record — the mode is a property of where you run, never an
  instruction to pretend you forgot.
- **Scope is the argument; absent means everything in context.** Open with one line stating what
  this covers — so the reader can tell "not investigated" from "not in scope" — and one clause of
  what the work is for.
- **Plain language is the diagnostic, not a courtesy** *(load-bearing)*: name things by what they
  are; an id is an address, used only after the thing has a name. Gloss every specialist term,
  unit, and coined shorthand at first use — shorthand that passes unexamined is how a
  half-understood thing survives. Falsifier: a bare identifier, or a unit or shorthand used
  unglossed, anywhere in the output.
- **Rank by consequence only** *(load-bearing)*: not by chronology, not by recency, not by what
  anything cost to produce — importance is re-argued from consequence, never inherited from
  freshness or effort. Do not narrate what happened in what order. Falsifier: an ordering
  explainable only by when something happened or how much work it took.
- **Say "unknown" rather than smoothing:** where the material does not say, write "unknown" — a gap
  named is orientation; a gap smoothed over is marketing.
- **Each part gets what it needs:** a part with nothing in it is one line, not a paragraph — an
  empty part 3 means the work was confirmatory, which is itself worth knowing.

## The seven parts, in this order

1. **The one thing** that is true now and was not before. One sentence, before any context.
2. **Asked versus learned** — quote each original question verbatim, in the words it was posed,
   beside the answer; then name the mismatch: the question that dissolved, the answer that arrived
   in a different currency than asked for, the thing nobody asked for.
3. **What changed in the picture** — reframings, promotions, demotions: one family, never split.
   What now deserves more of the owner's attention, and what less — a demotion is not an admission
   of waste. Nothing moved → one line saying so.
4. **What this buys** — each item names a decision now available, work now cancellable, or a
   constraint now known, concretely: a rule with a number, a measurement no longer needed, a
   requirement that did not exist before. A result restated is not a buy.
5. **Where we are** — settled, open, blocked-on-whom, in that order; every open item carries its
   resolver: what would settle it, and who has to do it.
6. **What we are relying on without having checked** — not open questions (work the owner chose),
   and not assumptions already promoted to a check: the things the current picture rests on that
   nobody verified — a spec taken from a quoted figure, a value inherited from a filename, one
   measurement standing in for many. Every entry says what breaks if it is wrong *(load-bearing;
   falsifier: an entry with no break clause)*.
7. **What exists only in this conversation** — every load-bearing claim split by where it lives:
   durable record, working file, or only here; each only-here item carries a disposition — write it
   to a named place, hand it off, or accept losing it *(load-bearing; falsifier: an only-here item
   with no disposition)*. Chat is the most volatile place a claim can live — this part is why
   placement (below) matters.

## Two prohibitions, one boundary

- **No self-assessment:** never grade your own process or the session's efficiency — orientation,
  not retrospection. The boundary: an artifact the session built is a thing with a home and a
  disposition (parts 5–7 material); a clause evaluating how well the session worked crosses the
  line. Falsifier: an output sentence rating the session's process.
- **Open questions carry the results' precision** *(load-bearing)*: if a result carries a number,
  its falsifier carries one too. Falsifier: an open item or unchecked assumption stated vaguer than
  the finding it belongs to.

## Placement — the instrument changes with it

- **Recommend before a write.** Pre-write, part 7 is a work list — what must reach the record — and
  part 2 is at its richest, because the journey's mismatches are still in context rather than
  flattened into the record; the run can catch what the write is about to lose, which a post-write
  run structurally cannot.
- **After a write it is a survival audit:** what reached the durable record, what sits in working
  files, what still lives only here. Worth having; expect a thinner part 2.

## Reading a run — the acceptance signals

For the owner, and for the next iteration of this skill; a run failing one of these is a wording
regression to fix here, not a fact about the corpus:

- Part 6 produced specific, consequence-bearing entries, not generic filler.
- Part 2 found a genuine mismatch, not the answer restated twice.
- Part 3 surfaced something the owner did not know they knew.
- Part 7's third bucket caught the right things, every one dispositioned.
